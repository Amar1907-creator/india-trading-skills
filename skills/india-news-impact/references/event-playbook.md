# Indian market event playbook

Typical first reactions. Real reactions depend on expectations: if the market expected a rate cut, the cut itself can
cause a "sell the news" fall. Always check what was expected.

## Macro and policy

| Event | Usually helped | Usually hurt | Notes |
|-------|----------------|--------------|-------|
| RBI repo rate cut | Banks, NBFCs, Realty, Auto, consumer durables | | Lower loan rates. Bank margins can shrink later |
| RBI rate hike / hawkish tone | | Realty, Auto, NBFCs, rate-sensitive midcaps | |
| CRR cut | Banks (more money to lend) | | |
| High CPI inflation | | Rate-sensitive sectors | Raises the odds of a rate hike or delay |
| Strong GDP data | Banks, Capital goods, Cyclicals | | |
| Union Budget capex increase | Infra, Capital goods, Cement, Railways, Defence PSUs | | Budget is usually on 1 Feb |
| Capital gains tax increase | | Whole market (short term) | |
| STT increase on F&O | | Brokers, exchanges (BSE), capital-market stocks | |
| Good / normal monsoon (IMD forecast) | FMCG, tractors, 2-wheelers, fertilisers, agri | | |
| Poor monsoon | | Same as above | Food inflation risk |
| GST rate cut on a product | That product's makers | | |

## Global

| Event | Usually helped | Usually hurt |
|-------|----------------|--------------|
| US Fed rate cut | FII inflows, broad market | |
| US Fed hawkish | | FII outflows, broad market |
| Rupee weakens | IT, Pharma, textile exporters | OMCs, airlines, importers |
| Crude oil up | ONGC, Oil India | BPCL, HPCL, IOC, Paints, Tyres, Airlines, Chemicals |
| Crude oil down | OMCs, Paints, Airlines | ONGC, Oil India |
| China stimulus / metal prices up | Tata Steel, JSW, Hindalco, Vedanta | |
| US tech results / AI spending strong | TCS, Infosys, HCL, Wipro and other IT | |
| War / geopolitical shock | Defence, Gold | Broad market, Airlines |

## Company and market

| Event | Typical effect |
|-------|----------------|
| Results beat estimates | Stock up, unless the guidance is weak |
| Results miss / weak guidance | Stock down, sometimes the whole sector |
| Promoter buying from the market | Positive confidence signal |
| Promoter pledge rising | Negative; a forced-selling risk |
| Large block deal | Depends on who bought and who sold |
| SEBI action / auditor resignation | Strongly negative |
| Inclusion in Nifty / MSCI index | Positive (passive buying) |
| Heavy FII selling for many days | Large-caps under pressure |
| Strong DII / SIP inflows | Cushions falls |
