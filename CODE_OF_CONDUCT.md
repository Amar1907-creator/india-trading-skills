# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and welcoming, especially to beginners. Every question is a fair question.
- Disagree about ideas, not people.
- No harassment, insults, or discriminatory language of any kind.
- **No promotion of tips, paid "calls", Telegram/WhatsApp groups, or unregistered advisory services** in issues,
  discussions or pull requests. This project exists partly to protect people from those.
- No sharing of anyone's personal data or account details.

## Reporting

If someone breaks these rules, report it to the maintainer through a
[private GitHub security advisory](https://github.com/Amar1907-creator/india-trading-skills/security/advisories/new) or by contacting
[@Amar1907-creator](https://github.com/Amar1907-creator). Reports are kept confidential.

Maintainers may remove comments, close issues, or block users who break this code.
